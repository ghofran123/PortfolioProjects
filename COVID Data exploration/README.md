# COVID-19 Data Exploration

## Overview
This project analyzes global COVID-19 data to study the relationship between infections, mortality, and vaccination rollout across countries and over time.

The goal is to transform raw epidemiological data into structured metrics that allow meaningful comparison between regions and time periods.

---

## Data Sources
- CovidDeaths.xlsx  
- CovidVaccinations.xlsx  

---

## Tools & Techniques
- SQL for data extraction and transformation  
- Joins across datasets (deaths + vaccinations)  
- Window functions for cumulative calculations  
- CTEs and temporary tables for structured analysis  
- Views for reusable analytical outputs  

---

## Analytical Focus
- Infection rate vs population across countries  
- Mortality rate trends and geographic variation  
- Global evolution of COVID-19 cases and deaths  
- Vaccination rollout progress over time  
- Comparative analysis across countries and continents  

---

## Key Analytical Outputs
- Computed infection rates relative to population size  
- Identified countries with highest burden of cases and deaths  
- Tracked cumulative vaccination progress using rolling calculations  
- Built reusable dataset views for visualization and reporting

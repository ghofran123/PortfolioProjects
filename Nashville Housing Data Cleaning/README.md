# Nashville Housing Data Cleaning

## Overview
This project focuses on cleaning and preparing Nashville housing data to improve data quality and ensure consistency for further analysis and reporting.

The goal is to transform raw housing records into a structured and reliable dataset suitable for analytical and business use cases.

---

## Data Sources
- Nashville_housing_data.xlsx  

---

## Tools & Techniques
- SQL for data cleaning and transformation  
- Handling missing and inconsistent values  
- Duplicate detection and removal  
- Standardization of date and text formats  
- Column splitting and data restructuring  

---

## Analytical Focus
- Identifying incomplete or inconsistent records  
- Standardizing housing and ownership information  
- Removing duplicate entries to improve data integrity  
- Converting raw fields into analysis-ready formats  
- Improving dataset consistency for downstream analytics  

---

## Key Analytical Outputs
- Cleaned and standardized housing dataset  
- Removed duplicate and invalid records  
- Structured date and address fields for improved usability  
- Improved overall dataset quality and consistency  

---

## Outcome
The project demonstrates practical SQL-based data cleaning techniques used to enhance dataset reliability, making the data more suitable for accurate analysis and reporting.

# Movies Data Correlation Analysis

## Overview
This project analyzes movie industry data to identify relationships between financial performance, audience reception, and production characteristics.

The goal is to uncover meaningful correlations between movie features and better understand the factors associated with commercial success.

---

## Data Sources
- movies.csv.zip  

---

## Tools & Techniques
- Python for data analysis and preprocessing  
- Pandas and NumPy for data manipulation  
- Data cleaning and missing value handling  
- Correlation analysis for relationship discovery  
- Data visualization for trend and pattern exploration  

---

## Analytical Focus
- Correlation between budget and gross revenue  
- Impact of movie genre and release year on performance  
- Relationship between ratings, votes, and revenue  
- Identification of strongest variables influencing movie success  
- Exploration of financial and audience-related trends  

---

## Key Analytical Outputs
- Computed correlation matrix across numerical features  
- Identified strong positive relationships between budget and gross earnings  
- Analyzed voting and rating patterns across movies  
- Visualized feature relationships using plots and heatmaps  

---

## Outcome
The analysis highlights how production budget, audience engagement, and other movie characteristics relate to financial performance, providing insights into the factors most associated with box office success.
